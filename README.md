# KTR WebSolution

Static business website for KTR WebSolution, a web design and development service for Indian small businesses, startups and local brands.

## Pages

- Home
- Services
- Pricing
- Portfolio
- About
- Blog
- Contact
- Privacy Policy
- Terms and Conditions
- Refund Policy

## Tech

- HTML
- CSS
- JavaScript
- Static hosting ready

## Project Notes

- Forms open WhatsApp with formatted enquiry details.
- Google Sheet lead capture can be connected later with an Apps Script endpoint.
- SEO pages, sitemap and legal pages are included.
- Portfolio examples are shown as sample concepts until real client screenshots are approved.
- Real testimonials, client names, screenshots and results should be published only with client permission.

## Deployment

Upload the website files to GitHub and deploy with a static hosting service such as Vercel or GitHub Pages.

Do not commit private setup URLs, API keys, payment details or client private data to a public repository.
